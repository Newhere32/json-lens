# Contributing

Thanks for considering a contribution. Please open an issue first for substantial changes so the scope can be discussed. Small documentation fixes can be submitted directly as a pull request.

## Before opening a pull request

1. Explain the problem and the proposed change.
2. Add or update tests for changed behaviour.
3. Run the test suite from the repository root:

   ```bash
   python -m unittest discover -s tests -v
   ```

4. Update the README when commands, limitations, or user-facing behaviour change.
5. Keep changes focused and avoid adding dependencies without a clear reason.

Please submit work you have reviewed and understand, and describe any limitations honestly.
